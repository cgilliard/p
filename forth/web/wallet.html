Payments by file, without an address: you make a payment file, the person you're paying answers it, and you finalize their answer.

Make a payment file

  1. Give the payment file to the person you're paying.
  2. They answer it and send a file back.
  3. Finalize that file below: the payment is signed and sent.

Answer a payment file

Answer a payment file someone gave you. Then give your answer back to them; they finalize it.

Finalize an answer

Finalize the answer to a payment file you made: it's signed and sent to the network.
